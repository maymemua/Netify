# Màn hình mẫu 023

Tài liệu giả lập dùng cho test. Màn hình Nút mẫu 023 hiển thị danh sách bản ghi mẫu.

## Thông tin chung

| Mục | Giá trị |
|---|---|
| Mã màn hình | MAU-023 |
| Người dùng | Vai trò mẫu |

## Mô tả giao diện

### Bộ lọc

Bộ lọc theo trạng thái mẫu và theo Nút mẫu 026.

#### Quy tắc

- Chỉ hiển thị bản ghi ở trạng thái đã duyệt (giả lập).
- Khi bấm Xuất file thì hệ thống tạo tài liệu mẫu.
